# Mbandeni Mineral Water Website

Static website for Mbandeni Mineral Water. Customers can choose water products, fill in their details, and send an order by WhatsApp or email.

## Current Prices And Hours

- Water refill: R1
- 500 ml bottle: R6
- 1.5 L bottle: R12
- Ice cubes: R20
- Custom water bottles: request quote
- Open Monday to Sunday, 07:00 - 19:30
- Location: Empangeni, Eniwe Reserve, R102

## Files

- `index.html` - main website page
- `styles.css` - responsive design
- `script.js` - product cart and order message
- `assets/mbandeni-bottle.svg` - local product image

## Update Contact Details

Current phone number:

- `0824778567`
- WhatsApp format used by the website: `27824778567`

To change it later, open `script.js` and replace:

```js
whatsappNumber: "27824778567",
email: "orders@mbandeniwater.co.za"
```

Use your real WhatsApp number in international format, without spaces or plus sign. Example: `27821234567`.

Also update the call and WhatsApp links near the bottom of `index.html`.

## Publish On GitHub Pages

1. Create a new GitHub repository.
2. Upload these files.
3. Go to repository `Settings`.
4. Open `Pages`.
5. Choose the main branch and root folder.
6. Save, then wait for GitHub to publish the website link.
